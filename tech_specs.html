📐 Pixel Wall - Specifiche Tecniche

Documentazione tecnica dell'implementazione del sistema di Crowdfunding "Pixel Wall".

Ultimo Aggiornamento: 04/01/2026

1. Architettura del Sistema

Il sistema è basato su un'architettura Serverless-like (senza database relazionale) utilizzando file JSON flat per la persistenza dei dati, gestiti tramite PHP con lock atomici per garantire la consistenza durante le scritture concorrenti.

  • Frontend: HTML5 Canvas, Vanilla JS, CSS3 (No Frameworks).
  • Backend: PHP 8.x (API RESTful), Node.js (Script di manutenzione/reset).
  • Pagamenti: Stripe PaymentIntent API (Verifica Server-side).
  • Storage: JSON Files (Intera griglia e transazioni).

2. Struttura Dati (JSON)

I dati risiedono nella sottocartella Pixel_wall/data.

Nome File Tipo Descrizione Schema Esempio
data/wall_data.json Data Contiene lo stato visivo attuale della griglia. { "x,y": "#RRGGBB", ... }
data/wall_preset.json Config Pixel immutabili (Logo MR) caricati al reset. { "x,y": "#RRGGBB" }
data/transactions.json Log Registro storico di tutti i pagamenti validati. [{ "id": "pi_...", "amount": 10.5, "date": "..." }]
data/pixel_owners.json Private Associa le email degli utenti ai pixel posseduti. { "email@test.com": { "pixels": ["10,10"], "txns": [...] } }
data/winners.json Game Elenco dei vincitori del Golden Pixel. [{ "pixel": "100,50", "email": "...", "date": "..." }]
data/winners_silver.json Game Elenco dei vincitori dei 50 Silver Pixel. [{ "pixel": "...", "email": "...", "date": "..." }]

  • private/secret_gold_pixels.php: Array PHP con le 10 coordinate Gold. Protetto.
  • private/secret_silver_pixels.php: Array PHP con le 50 coordinate Silver. Protetto.
  • private/admin_winners_x9k2m.php: Dashboard segreta per visualizzare i vincitori.
  • private/Stripe_keys_a7b2c9.php: Chiavi API Stripe (Rinominate e spostate).

3. Flusso Funzionale

A. Rendering Griglia

  1. Il client scarica data/wall_preset.json (base) e interroga wall-api.php (sovrappone i pixel utente).
  2. Canvas HTML5 renderizza i pixel 1:1.
  3. Zoom e Pan sono gestiti via trasformazioni di coordinate JS (senza ridisegno continuo del DOM).
  4. Ottimizzazione: Viene usato un Offscreen Canvas per cacheare i pixel statici.

B. Pagamento e Salvataggio (Critico)

  1. Fase 1 (Client): JS calcola l'area e i pixel, chiama Stripe per ottenere un clientSecret.
  2. Fase 2 (Stripe): Crea un PaymentIntent con metadata (numero pixel).
  3. Fase 3 (Conferma): Utente paga. Al successo, Stripe invia conferma al client.
  4. Fase 4 (Salvataggio Sicuro):
    • Il client invia i pixel + ID Transazione a wall-api.php.
    • Il server chiama le API di Stripe (Server-to-Server) usando la Secret Key.
    • Verifica che lo stato sia succeeded.
    • Verifica che il numero di pixel pagati corrisponda a quelli inviati.
    • Se OK, acquisisce un Lock Esclusivo (flock) su data/wall_data.json e scrive.

C. Sistema Golden Pixel

La logica di vittoria è Server-side. Durante il salvataggio dei pixel:

$goldPixels = include 'private/secret_gold_pixels.php';
$found = array_intersect($nuovi_pixel, $goldPixels);
if ($found) {
    // Registra vincitore in winners.json
    // Restituisce isWinner = true al client
}

Il client mostra il modale di vittoria solo se il server conferma.

D. Sistema Silver Pixel

Funziona in parallelo al Gold. Se un pixel non è Gold, viene controllato nell'array Silver:

  • 50 pixel vincenti (generati per non sovrapporsi a Gold o Preset).
  • Restituisce isSilverWinner al client.
  • Attiva il modale "Silver Pixel Found" e l'icona aggiornata nel HUD.

4. Manutenzione e Reset

È disponibile uno script Node.js per resettare l'ambiente in produzione (o test).

node Pixel_wall/scripts/reset_wall.js

Cosa fa:

  1. Ripristina data/wall_data.json allo stato del preset.
  2. Svuota transazioni, log proprietari e vincitori (Gold e Silver).
  3. Utilizza scripts/generate-gold-pixels.php per calcolare 10 coordinate Gold e 50 Silver (salvati in private/, evitando le aree occupate dal preset).
  4. Svuota access_logs.json.

6. Pagine Accessorie

A. Statistiche (stats.php)

  • GeoIP & Flags: Integra ip-api.com per ottenere la nazione e mostra la bandiera tramite flagcdn.com.
  • Privacy: Maschera IP pubblici (es. 87.12.***.***).
  • UX: Grafici a torta con smart-labels (posizionate fuori se fetta < 5%). Tabella visitatori con paginazione "Show More".

B. Hall of Gold (winners.php)

  • Visualizza "Hall of Gold" e "Hall of Silver" in un'unica pagina.
  • Supporta deep-linking tramite anchor (#silver) per scroll automatico dal HUD.
  • Mostra statistiche in tempo reale (Contatori trovati/totali).

5. Versioning e Cache

Per evitare problemi di cache sui browser degli utenti, le risorse critiche usano un parametro di versione incrementale:

  • style.css?v=51
  • pixel-wall.js?v=49
  • translations.js?v=7
